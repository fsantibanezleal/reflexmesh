# Design

Keep the corrected 19,488-episode tree immutable. Read its core index and verify all 14,400 trace hashes before measuring saturation and within-template seed variability. The resulting JSON binds the original index digest and is labeled post-hoc. C07 cancellation repair lives in the policy and is validated by actual C07 runs; it is never substituted into the frozen score.

The new suite builds independent disposable workspaces for D01–D08. Each has three dependent registered file effects, three type-compatible choices per stage, opaque IDs, seeded candidate order and independent stage-value truth. Two task families vary the required transformation across seeds. The runner reuses all twelve existing frozen checkpoints and the configured real planner. A separate lineage, manifest, full trace tree and audit report bind the new denominator. CI checks the committed result without rerunning model inference.

File-workflow validation binds read/write paths and the write-content SHA-256 to each declared postcondition before starting any step. An existing unrelated file cannot make a different write appear verified.
