# local-controller design

Controller schedules independent goals and dependency nodes, checks cancellation and handles bounded asynchronous planners. The policy_factory owns one mutable policy per goal. Explicit immutable process templates and scoped UTF-8 file operations are the host capability boundary. Loopback auth and single-use previews protect the browser-to-runtime seam.

The product SDD defines the scope and deploy boundary. Requirements refer to executable gates and are not inferred from successful rendering or method names.
