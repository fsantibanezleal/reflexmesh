# learning-metacontrol design

Candidate features encode permitted observations and operation semantics, excluding identity and future outcomes. Fit/calibrate/select allocation at distinct seeds 50000/60000/70000. Recurrent hidden state belongs to one episode. The gate predicts positive executed incremental utility; surprise/evidence rules remain separately labeled. Fixed-gate ablations remove one component without held-out retuning.

The product SDD defines the scope and deploy boundary. Requirements refer to executable gates and are not inferred from successful rendering or method names.
