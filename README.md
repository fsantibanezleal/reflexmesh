# reflexmesh

An event-driven software-control runtime with bounded learned policies, verified effects and asynchronous deliberation.

Implementation is in progress. This repository does not yet claim a released package, trained policy, benchmark result or general-intelligence capability.

The engine separates authoritative state and capabilities from learned policy state. Python provides research and integrations; Rust provides the native broker and control primitives. Neuraxis is the separate scientific workbench that consumes this package.
